# Monitoring Intelligence Platform

منصة رصد وتحليل رقمي داخلية — واجهة عربية RTL، تعمل حالياً في **الوضع التجريبي** بلا أي اتصال بـ X API.

> **قبل أي تشغيل حي:** اقرأ [docs/X_API_STRATEGY.md §1](docs/X_API_STRATEGY.md).
> X تبيع اشتراكات بسقف منشورات، لا طلبات مُسعّرة. ميزانية $20/شهر ≈ **1,000 منشور شهرياً** (~33 يومياً لكل البرامج مجتمعة).

---

## التشغيل

```bash
pnpm install
cp .env.example .env

docker compose -f infra/docker-compose.yml up -d   # Postgres 16 + pgvector · Redis 7
pnpm db:push                                        # المخطط والتقسيمات
pnpm db:seed                                        # الأدوار والبرامج والقواميس والميزانيات

pnpm --filter @mip/api dev                          # http://localhost:3001
pnpm --filter @mip/web dev                          # http://localhost:5173

# تصنيف التفاعلات (Stage 2) يحتاج apps/ai — Python 3.12، منفصل عن pnpm/turbo
cd apps/ai && python -m venv .venv
./.venv/Scripts/pip install -e .                    # أو ./.venv/bin/pip على macOS/Linux
./.venv/Scripts/python -m uvicorn app.main:app --port 8000
```

**حسابات التطوير** (غيّرها قبل أي نشر):

| الحساب | كلمة المرور | الدور |
|---|---|---|
| `admin@mip.local` | `Admin@12345` | مدير النظام |
| `viewer@mip.local` | `Viewer@12345` | مستعرض (قراءة فقط) |

## الأوضاع الثلاثة

| الوضع | ENV | السلوك |
|---|---|---|
| **تجريبي** (افتراضي) | `LIVE_X_API=false` | بيانات وهمية عربية واقعية. **لا يوجد مسار كود يصل إلى X إطلاقاً.** |
| **تشغيل جاف** | `LIVE_X_API=true`<br>`X_DRY_RUN=true` | كل شيء حقيقي عدا الطلب: الجدولة تعمل، الميزانية تُقيّم، الاستعلام يُبنى ويُسجَّل «سيُنفَّذ هذا الاستعلام». صفر استهلاك. |
| **حي** | `LIVE_X_API=true` | طلبات فعلية. يتطلب مفتاحاً صالحاً وميزانية مُهيّأة. |

**الوضع التجريبي ليس بيانات تجميلية:** العيّنات تخلط شكاوى حقيقية الصياغة بالعامية السعودية مع إعلانات عقارية و spam — لأن نتائج X الخام أغلبها ضجيج، وهذا ما تتدرّب عليه محركات الفلترة والدقة. والأهم: **المُطابِق يفهم صيغة استعلام X فعلياً** (`packages/x-collector/src/query-match.ts`)، فاستعلام أفضل يعطي نتائج أفضل — بلا ذلك لن تتعلّم دورة «اختبر → حسّن → أعد الاختبار» شيئاً.

## الاختبارات

```bash
node scripts/e2e-check.mjs        # 64 فحصاً للمسار الحرج كاملاً
npx tsx scripts/matcher-test.mts  # صحة مُطابِق استعلامات X
node C:/Users/<you>/.claude/skills/browser-automation/browser.mjs \
  http://localhost:5173/ --script ./scripts/ui-check.mjs   # فحص الواجهة
```

`e2e-check.mjs` يتحقق فعلياً — لا يفترض — من:
- المستعرض **يُمنع** من مفتاح الإيقاف (403)
- ترقية استعلام غير مُختبَر **مرفوضة** (409)
- الجمع من استعلام غير نشط **مرفوض**
- الميزانية **توقف** الطلب فعلياً عند بلوغ الحد، والرفض يُسجَّل
- مفتاح الإيقاف **يوقف الجلب** بينما تبقى المنصة تعمل
- `since_id` يمنع إعادة الجلب · التكرار يُكتشف بالمحتوى لا بالمعرّف فقط

## الحدود الحالية (بصراحة)

- **المرحلتان 2 و 3 لم تُبنيا بعد.** التصنيف حالياً: فلترة قواعد + إرشاد شفّاف فوق القاموس. الحقل `stage` يُسجَّل من اليوم الأول ليبقى هرم التكلفة قابلاً للقياس، لكن لا embeddings ولا LLM بعد.
- **لا Worker.** الجدولة المتكررة (`collect:query` وغيرها) في Phase 1.D. حالياً الجمع يدوي عبر زر «جمع الآن» — ويمر على **نفس** البوابة والمحاسبة تماماً.
- **بوابة الميزانية على Postgres لا Redis.** ذرّية وصحيحة عبر قفل صفوف داخل معاملة؛ مسار Redis السريع مؤجَّل.
- **الميزانيات المزروعة تقديرية** (1000 وحدة/شهر = $20). أرقام باقة X يجب التحقق منها من صفحة أسعارهم قبل التشغيل الحي.

## قواعد غير قابلة للتفاوض

1. لا استدعاء لـ X خارج `XApiGateway` (`packages/x-collector/src/gateway.ts`).
2. لا طلب X بلا `ALLOW` من `BudgetService`.
3. لا استعلام في الإنتاج بلا اختبار Sandbox ناجح (≥ 70% دقة).
4. الافتراضي دائماً `LIVE_X_API=false`.
5. لا أسرار في Git ولا في السجلات (الـ logger يحجبها).
6. لا بيانات داخلية إلى مزود AI خارجي بلا `ALLOW_INTERNAL_DATA_TO_EXTERNAL_AI=true`.
7. كل مخرج AI موسوم بأنه مولَّد آلياً.
8. كل عملية حساسة في `audit_log`.
9. **لا حذف للمنشورات المفلترة** — هي مصدر قياس نسبة الضجيج لكل كلمة.
10. الأسعار والحدود في `settings` لا في الكود.
